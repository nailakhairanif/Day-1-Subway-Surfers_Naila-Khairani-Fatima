Repository : Repository merupakan tempat penyimpanan terpusat untuk file-file sebuah proyek, misalnya kode program, dokumentasi, gambar, dan konfigurasi. Repository juga melacak perubahan-perubahan yang terjadi pada suatu file: siapa yang mengubah, kapan, dan apa yang diubah.

Tujuan dan kegunaan dari suatu repository adalah sebagai berikut:
1. Menyimpan dan mengorganisir proyek di satu tempat yang rapi dan aman (ada cadangan di server).
2. Melacak riwayat perubahan (version control), sehingga kesalahan bisa dibatalkan dan perkembangan proyek bisa ditelusuri.
3. Kolaborasi tim: banyak orang dapat mengerjakan proyek yang sama secara bersamaan tanpa saling menimpa pekerjaan.
4. Berbagi dan publikasi: proyek bisa dibagikan ke publik (open source) atau dibatasi untuk tim tertentu.
5. Dokumentasi dan manajemen proyek: biasanya dilengkapi README, pelacak isu (issues), dan review kode (pull request).

Rangkuman materi :

Prompt adalah instruksi yang diberikan kepada model untuk mendapatkan hasil tertentu.
Bentuk prompt bisa beragam, mulai dari oertanyaan sederhana, hingga instruksi yang rumit, atau potongan kode.
Sebuah prompt yang bagus memiliki Role, Task, Context, dan Format.

Role = Jelaskan apa peran AI tersebut

Task = jelaskan apa yang harus dilakukan/dibuat

Context = jelaskan yang dibutuhkan dan juga batasannya (requirements dan constraints)

Format = output yang dibutuhkan (misal code), cara kerjanya bagaimana, dan cara mengujinya.

Keuntungan  Prompt Engineering
1. Meningkatkan performa AI model
2. Mengurangi bias
3. Meningkatkan kontrol dan predictability 
4. Memberikan pengalaman yang lebih baik


Git/Github
Git = version control system yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file
Diciptakan oleh Linus Torvalds pada tahun 2005

Git workflow
Working directory = salinan dari satu versi proyek.
Staging area = file yang umumnya ada di dalam direktori.
Git directory = tempat di mana Git menyimpan metadata dan object database dari sebuah proyek.

Git vs Github
git = sistem version control
github = tempat menyimpan hasil git secara cloud

Perintah Dasar Git
git init  = mulai repo baru

git clone "url" = salin repo dari GitHub

git add . = pindahkan file ke staging area

git commit -m 'message' = simpan ke repository

git remote add <name> <url> = hubungkan ke remote

git push origin main = kirim ke GitHub

git pull origin main = ambil dan gabungkan perubahan
